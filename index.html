快速上手

  1. 启动：双击 start.bat（自动打开浏览器），或直接双击 index.html（离线功能全部可用）。
  2. 整篇论文：点击“上传论文”，支持 docx / pdf / doc / txt / md / rtf / html。上传后逐段降重，下载时按原格式导出（docx→docx、pdf→pdf…），Word 的标题样式、页边距、图片、表格均保留。老版 .doc 请用 start.bat 启动后上传。
  3. 段落降重：粘贴论文段落 → 选择论文类型与强度 → 点击“开始降重”。公式、参考文献标记、数字、专业术语会自动保护。
  4. 自查：点击“本地查重估算”，查看改写前后相似度变化与疑似重复片段。
  5. 导出：上传的论文点击“下载结果（原格式）”；手动粘贴的内容可复制，或导出为 Word（.doc）/ TXT 文件。
  6. AI 改写：填入 DeepSeek API Key 后可用（Key 仅存本机浏览器）。没有 Key 也能用全部离线功能。

降重策略说明

  • 同义词替换：内置 300+ 组学术同义词，按语境随机选取，同一词多次出现时自动换用不同说法。
  • 句式变换：关联词替换（因为→由于、但是→然而…）、“本文/本研究”等主语变体。
  • 长句拆分：把含多层递进的超长句拆成短句，符合学术写作规范。
  • 适度扩写：在关键处增加限定修饰（该模型→上述模型、重要→至关重要），强模式下可选。

自定义

  • 同义词：编辑 js/dictionary.js 的 SYNONYM_DICT（通用）与 MATH_SYNONYMS（数学建模专用）。
  • 术语保护：编辑 js/dictionary.js 的 MATH_TERMS 与 GENERAL_TERMS。
  • 知识库：编辑 js/knowledge.js。

重要提醒

降重的正确姿势是理解后用自己的话重写 + 规范引用。机械替换无法替代真正的写作能力，且任何规避学术不端检测的行为都违反《高等学校预防与处理学术不端行为办法》（教育部令第40号）。请务必人工核对 AI 与规则引擎输出的每一处修改，确保语义准确、表述通顺。
